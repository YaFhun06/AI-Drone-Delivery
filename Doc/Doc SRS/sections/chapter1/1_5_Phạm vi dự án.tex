\subsection{Project Scope}

\textbf{Functional Scope:}

\begin{itemize}
  \item In-Scope: Research, analyze, design, and develop the software platform for drone delivery management operations.
  \item Out-of-Scope: Drone hardware design and assembly, and flight control system development.
\end{itemize}

\textbf{Data \& Experimentation:} Evaluate system feasibility and machine learning model accuracy using simulated datasets in small to medium-scale scenarios.
