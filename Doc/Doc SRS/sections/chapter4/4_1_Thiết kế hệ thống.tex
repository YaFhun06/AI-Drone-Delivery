\subsection{Kiến trúc triển khai}

Hệ thống SmartDroneDelivery được triển khai theo mô hình gồm frontend, backend, cơ sở dữ liệu và dịch vụ AI. Frontend được xây dựng bằng ReactJS/Vite, Backend sử dụng Python/Flask, cơ sở dữ liệu sử dụng PostgreSQL trên Supabase và các chức năng AI được cung cấp thông qua Gemini API.

\begin{itemize}

```
\item \textbf{Frontend Development Server:} ReactJS/Vite, cung cấp giao diện người dùng và thực hiện giao tiếp với Backend thông qua HTTP/REST API.

\item \textbf{Backend Development Server:} Python/Flask, xử lý REST API, xác thực, phân quyền và các nghiệp vụ chính của hệ thống.

\item \textbf{Database Service:} PostgreSQL trên Supabase, lưu trữ dữ liệu nghiệp vụ và kết nối với Backend thông qua biến môi trường \texttt{DATABASE\_URL}.

\item \textbf{AI Service:} Gemini API được Backend Flask tích hợp để hỗ trợ các chức năng ETA, chatbot và tóm tắt thông tin giao hàng.
```

\end{itemize}

Frontend gửi yêu cầu đến Backend thông qua HTTP. Backend tiếp nhận và xử lý yêu cầu, truy xuất hoặc cập nhật dữ liệu trên Supabase PostgreSQL và gọi Gemini API khi cần thực hiện các chức năng AI.

\subsubsection{Luồng triển khai}

Quá trình triển khai hệ thống được tổ chức theo luồng từ Frontend đến Backend, sau đó Backend thực hiện xử lý nghiệp vụ và tương tác với các dịch vụ liên quan. Backend sử dụng Alembic/Flask-Migrate để quản lý và cập nhật schema cơ sở dữ liệu. Frontend và Backend được khởi động với các tiến trình tương ứng trong môi trường phát triển.

Các thông tin cấu hình và dữ liệu bảo mật như JWT key, thông tin kết nối cơ sở dữ liệu và khóa API AI được quản lý thông qua biến môi trường. Hệ thống có cơ chế health-check nhằm kiểm tra trạng thái hoạt động của ứng dụng và kết nối cơ sở dữ liệu.
