\subsection{Kiến trúc triển khai}

Trong phiên bản hiện tại, hệ thống được chạy trong môi trường phát triển gồm frontend Vite, backend Flask và PostgreSQL trên Supabase. 

\begin{itemize}

    \item \textbf{Frontend Development Server:} ReactJS/Vite, chạy độc lập trong thư mục frontend.

    \item \textbf{Backend Development Server:} Python/Flask, xử lý API và nghiệp vụ chính của hệ thống.

    \item \textbf{Database Service:} PostgreSQL trên Supabase, kết nối qua biến môi trường \texttt{DATABASE\_URL}.

    \item \textbf{AI Service:} Gemini API được Backend Flask gọi cho ETA, chatbot và tóm tắt giao hàng khi đã cấu hình khóa API.

\end{itemize}

Frontend gọi Backend qua HTTP tại môi trường phát triển. Backend xử lý nghiệp vụ, truy xuất dữ liệu từ Supabase và gọi Gemini khi cần.

\subsubsection{Luồng triển khai}

Backend dùng Alembic/Flask-Migrate để cập nhật schema; frontend và backend được khởi động bằng các lệnh phát triển riêng. Chưa có Dockerfile.

Các secret như JWT key, mật khẩu database và khóa API AI được truyền qua biến môi trường. Endpoint health-check hiện kiểm tra trạng thái ứng dụng và database; HTTPS, reverse proxy và secret manager production là phạm vi triển khai sau.
